# pyatv 0.18.0 references

Pinned target: **pyatv 0.18.0**.

The `docs/` directory contains the pyatv Markdown reference files supplied for this project. They cover installation/getting started, concepts, supported features, protocols, command-line tools, and the project tutorial.

For implementation work, the most useful files are typically:

- `docs/getting_started.md`
- `docs/concepts.md`
- `docs/supported_features.md`
- `docs/atvremote.md`
- `docs/atvscript.md`
- `docs/tutorial.md`

The uploaded archive did **not** contain the upstream `examples/` directory or Python public-API source files. If those are later added, keep them pinned to the `v0.18.0` release rather than `master`.
